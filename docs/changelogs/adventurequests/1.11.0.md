### New
- Five new Kweebec farmer stories, bringing the villages to thirty-two.
- Make a scarecrow and set it up in a farmer's field, a copper hoe for a clumsy sproutling, a watering can for a gardener with a leaky bucket, and two hay bales for a barn soaked by the rain.
- Pick three ripe lettuces before the snails get there. The sproutling only asks when ripe lettuces grow nearby.

### Fixes
