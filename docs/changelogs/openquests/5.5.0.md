### New
- LootNpc quest type: NPCs of a group drop an item only for the quest, with a chance per kill and a drop guaranteed after a set number of tries.
- Each quest drop is announced in the chat, and a drop lost to a full inventory is reported.
- The fields of the OpenQuests assets are explained in the Asset Editor.

### Requirements
- Requires OpenQuests Core 5.5 or later.
